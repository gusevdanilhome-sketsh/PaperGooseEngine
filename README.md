# PaperGoose Engine

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Build status](https://github.com/your-username/papergoose-engine/actions/workflows/ci.yml/badge.svg)](https://github.com/your-username/papergoose-engine/actions)

**PaperGoose** — игровой 2D-движок для создания игр с глубокой физикой, разрушаемым пиксельным окружением и встроенным пиксель-арт редактором.  
Написан на C17, использует Vulkan (с программным fallback) и строгий контроль памяти без динамических аллокаций в игровом цикле.

## Ключевые возможности
- **Встроенный пиксель-арт редактор** с горячей перезагрузкой ассетов прямо во время игры.
- **Разрушаемое окружение** на уровне отдельных пикселей, совмещённое с симуляцией жидкостей и газов.
- **Физика на Chipmunk2D** с кинематическим контроллером персонажа, составными коллайдерами и сенсорами.
- **ECS-архитектура** с параллельной обработкой систем и гарантией отсутствия фрагментации памяти.
- **Двойной рендерер:** аппаратный на Vulkan и программный (software rasterizer) для headless-систем или слабых GPU.
- **Полноценная IDE** с редактором сцен, инспектором свойств, встроенной областью кода на C/C++ и сборкой в один клик.
- **Встроенный Git** для контроля версий прямо в редакторе.
- **Тайловые карты** с поддержкой ортогональных проекций, динамическое освещение, шейдерная постобработка, скелетная и спрайтовая анимация.
- **Аудиосистема** с 2D-позиционированием и загрузкой .wav/.ogg.

**Главная «киллер-фича»:** вы рисуете стену в редакторе, помечаете её как разрушаемую, и в игре она разлетается на пиксельные обломки, взаимодействующие с жидкостями и газами. Всё это видно мгновенно благодаря горячей перезагрузке.

## Цели проекта
1. Создать среду, в которой малая инди-команда (1–5 человек) может полностью разработать 2D-игру, не покидая редактора.
2. Обеспечить предсказуемую производительность за счёт полного контроля над памятью (запрет `malloc` после инициализации).
3. Предоставить уникальный инструментарий для игр с разрушаемостью на уровне пиксельной графики.
4. Оставаться полностью опенсорсным (MIT), позволяя разработчикам свободно модифицировать и распространять движок.

Подробное техническое задание с архитектурными решениями и критериями приёмки находится в [документе ТЗ](docs/specification.md).

## Быстрый старт (зависимости и сборка)
На текущем этапе (ранняя разработка) поддерживаются Windows (MinGW-w64) и Linux (Ubuntu 22.04+). Требуется **GCC** (C17), **CMake ≥ 3.21**, **Vulkan SDK 1.2+**.

```bash
# Клонирование репозитория
git clone https://github.com/your-username/papergoose-engine.git
cd papergoose-engine

# Настройка и сборка
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

Запуск редактора:

```bash
./build/papergoose-editor
```

Инструкции по установке зависимостей для вашей ОС смотрите в документации.
