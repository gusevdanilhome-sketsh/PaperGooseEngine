# PaperGooseEngine
**Paper Goose — 2D-игровой движок на чистом C со встроенным пиксель-арт редактором, реалистичной физикой и интегрированной системой контроля версий Git.**
> Движок полностью написан на чистом C с применением принципов Data-Oriented Design (DOD). Ориентирован на русскоязычных разработчиков инди-игр, предоставляя полную документацию, удобные инструменты и экосистему для творчества без границ.
---
  
## Ключевые возможности
* Производительность:** ECS-архитектура, написанная на C, обеспечивает минимальные накладные расходы и максимальную скорость.
* Интегрированный Пиксель-Арт Редактор:** Полноценный редактор с системой слоёв, покадровой анимацией и горячей перезагрузкой ассетов.
* Реалистичная 2D-физика:** Взаимодействие объектов, разрушаемое окружение, симуляция жидкостей и расширенная система частиц (на базе Chipmunk2D).
* Встроенный Git:** Удобный графический интерфейс для коммитов, веток и разрешения конфликтов прямо в редакторе движка.
* Полная Русскоязычная Экосистема:** Интерфейс, исчерпывающая документация и активное сообщество на русском языке.

## Быстрый старт
> **Важно:** Проект находится на стадии активной разработки. Инструкции могут меняться.
### Предварительные требования
* Компилятор C (GCC)
* CMake (версия 3.15+)
* Git
### Установка и запуск
1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```
2. **Сборка:**
```bash
mkdir build
cd build
cmake ..
make
```
3. Запуск демо-сцены:
```bash
./engine
```
